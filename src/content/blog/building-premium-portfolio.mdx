# Building a Premium Portfolio with Next.js 16 and Three.js

Creating a portfolio that truly stands out from the crowd requires more than just listing your projects. It demands thoughtful design, smooth animations, and a technical foundation that showcases your capabilities as a developer.

## Why Next.js 16?

Next.js 16 introduces the latest App Router paradigm, which allows you to build a hybrid application where some pages are fully server-rendered for maximum SEO performance, while interactive client components handle animations and user interactions.

> The App Router changes how we think about React applications. Instead of client-first thinking, we start with the server and selectively opt into client-side rendering.

## Setting Up the Three.js Background

The hero section uses `@react-three/fiber`, a React renderer for Three.js, to create an interactive 3D starfield:

```tsx
"use client";

import { useRef } from "react";
import { Canvas, useFrame } from "@react-three/fiber";
import { Stars } from "@react-three/drei";

function RotatingStars() {
  const ref = useRef(null);
  
  useFrame(() => {
    if (ref.current) {
      ref.current.rotation.x -= 0.0002;
      ref.current.rotation.y -= 0.0002;
    }
  });
  
  return (
    <group ref={ref}>
      <Stars radius={100} depth={50} count={5000} />
    </group>
  );
}
```

## Glassmorphism with Tailwind CSS

Glassmorphism is achieved using a combination of `backdrop-blur`, `bg-opacity`, and subtle borders:

```css
.glass-card {
  @apply bg-card/80 backdrop-blur-xl border border-white/5 shadow-2xl;
}
```

## What I Learned

Building this portfolio taught me several key lessons:

- **Server Components First**: Always start with server components and only switch to client components when absolutely necessary for interactivity.
- **Performance Matters**: Three.js can be heavy. Using `React.lazy` and `Suspense` to load the Canvas only when needed drastically improves initial load time.
- **MDX is Powerful**: Having a full MDX blog system inside your portfolio means you never need a CMS. Write, commit, and it goes live.

## Conclusion

A well-crafted portfolio is your most powerful career asset. It's the first impression you make on potential employers and collaborators. By combining the power of Next.js 16, Three.js, and Framer Motion, you can create an experience that is genuinely unforgettable.
